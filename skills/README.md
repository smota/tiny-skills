# Skills

Each independent skill lives at `skills/<class>/<skill-name>/SKILL.md`. Supported classes
are `personal`, `research`, `writing`, and `software-engineering`.

Browse the [root skill catalog](../README.md#skill-catalog) for available skills, prerequisites,
and installation commands. Each skill's own `SKILL.md` is the authority for detailed usage.

To add a skill, start with [the template](../templates/SKILL.md), follow the
[authoring guidance](../docs/authoring.md), and update the root catalog in the same change.
